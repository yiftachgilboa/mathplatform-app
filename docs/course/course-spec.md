# אפיון — אתר הקורס kidodo (עמוד הקורס אחרי כניסה)

גרסה 0.4 · 2026-11-13 · עיצוב: `course-design.md` · למימוש עם Claude Code

---

## 1. החלטה מרכזית: לא בונים אתר חדש

הקורס נבנה **בתוך `mathplatform-app`** כנתיב חדש `/course`, ולא כאתר נפרד.

מה מקבלים בחינם ממה שכבר קיים:

| צריך | כבר קיים ב-mathplatform-app |
|---|---|
| הרשמה / כניסה / Google | `app/login`, `auth/callback`, Supabase Auth |
| כניסת ילד בלי סיסמה | שם + קוד משפחה (`api/child-login`) |
| ילד עם שם ואווטאר | טבלת `children` (כולל עמודת `avatar`) |
| הרשאות גישה | טבלת `parent_access` (כבר נוצרת `tier:free` לכל הורה) |
| משחקי תרגול | תיקיית `app/games/*` + SDK + `/play/[gameId]` |
| כוכבים ומטבעות | אירועי SDK (`ANSWER`, `GAME_OVER`) + `progress` |
| התקדמות פנימית | `game_internal_progress` + API route קיים |
| אחסון סרטונים | Supabase Storage, bucket `kidodo-media` |
| עורות / צבעים | `lib/themes` |

**התוצאה:** מי שקנה את הקורס הוא משתמש רגיל של MathPlatform עם הרשאה נוספת. אותו חשבון, אותם ילדים, אותם משחקים.

## 2. זרימת משתמש

```
עמוד נחיתה (kidodo) → תשלום → webhook → parent_access: 'course:kidodo'
                                   ↓
mathplatform-app/login?next=/course
                                   ↓
     /course  ── אין אף קורס? → עמוד "הקורס לא נרכש" + קישור לעמוד הנחיתה
              ── קורס שנרכש ועוד לא שויך לילד? → /course/[courseId]/welcome
              ── קורס אחד פעיל → /course/[courseId]/[השיעור הנוכחי]
              ── כמה קורסים → מסך "הקורסים שלי" (כרטיס לכל ילד + קורס)
```

- הרשאת קורס: שורה ב-`parent_access` עם `access_key = 'course:<courseId>'` (למשל `course:kidodo-g1`).
- עד שיש סליקה: מוסיפים את השורה ידנית ב-Supabase.

### 2.1 כמה קורסים לאותו הורה (מוכן מעכשיו)
- **רכישה = קורס אחד לילד אחד.** הורה יכול לקנות כמה קורסים (כיתה א׳ לילד אחד, כיתה ג׳ לאחר) — הכל באותו חשבון.
- כל קורס הוא קובץ תוכן נפרד ו-`courseId` נפרד. הקוד אחד לכל הקורסים.
- `courseId` מופיע בכתובת, בטבלאות ובהרשאה — כך שהוספת קורס שני לא דורשת שינוי קוד, רק קובץ תוכן ושורת הרשאה.
- מסך "הקורסים שלי" מופיע רק כשיש יותר מקורס אחד; עם קורס אחד נכנסים ישר.

## 3. כניסה ראשונה — `/course/[courseId]/welcome`

מופיע פעם אחת לכל קורס שנרכש (לא לכל כניסה).

מסך אחד, שני שלבים קצרים, ואז ישר לשיעור 1.

1. **"איך קוראים לך?"** — שדה שם הילד.
   - אם להורה כבר יש ילדים ב-MathPlatform: מציגים אותם ככרטיסים + "ילד חדש". בחירה בילד קיים מדלגת על השם.
2. **"בחר את הדמות שלך"** — רשת של 6–8 דמויות kidodo (תמונות, לא אימוג׳י).
3. כפתור גדול **"יוצאים לדרך!"** → שומר → `/course/[courseId]/lesson-01`.

- ילד שכבר רשום לקורס לא מוצג לבחירה לאותו קורס פעם שנייה.

נשמר: `children.name`, `children.avatar` (מזהה דמות, למשל `char-03`), ושורה ב-`course_enrollments`.

## 4. מבנה עמוד הקורס — `/course/[courseId]/[lessonId]`

כיוון RTL. מובייל פירסט.

```
┌──────────────────────────────────────────────────────────────┐
│ [יציאה ⎋]                    kidodo      שלום, נועה! [🙂דמות] │  ← כותרת
├──────────────────────────────────────────┬───────────────────┤
│                                          │  השיעורים שלי      │
│   שיעור 3 · מפתח המדרגות                 │  ✓ 1 פירוק         │
│   [דמות השיעור]  "עולים במדרגות עד 10"    │  ✓ 2 השלמה לעשר    │
│                                          │ ▶ 3 מדרגות  ◄בולט  │
│   ①סרטון ②התנסות ③משחק ④העשרה ⑤מבחן      │  ○ 4 מעלית        │
│                                          │  ○ 5 הקטנה        │
│   ┌──────────────────────────────────┐   │  ○ 6 טיפוס        │
│   │                                  │   │  ○ 7 גלישה        │
│   │        אזור התוכן של השלב        │   │  ○ 8 הדבקה        │
│   │                                  │   │  ○ 9 גנב          │
│   └──────────────────────────────────┘   │  ○ 10 שודד        │
│   [→ קודם]   דיוק: 84%   [הבא ←]          │                   │
└──────────────────────────────────────────┴───────────────────┘
```

### 4.1 כותרת עליונה
- **ימין:** "שלום, [שם הילד]!" + עיגול עם הדמות שבחר.
- **שמאל:** כפתור יציאה (אייקון + "יציאה"). לחיצה → `signOut` → `/login`.
- מרכז: לוגו kidodo.

### 4.2 עמודת שיעורים (ימין)
- 10 כרטיסים, כל אחד: מספר, שם המפתח, אייקון/דמות קטנה, ו-5 נקודות קטנות שמראות כמה שלבים הושלמו.
- **מצבים:**
  - הושלם — וי ירוק, צבע רגוע.
  - **נוכחי — גדול יותר, צבע השיעור מלא, מסגרת זוהרת, דמות מונפשת קלות.**
  - עתידי (○) — **אפור, אבל פתוח.** לחיצה נכנסת אליו. אין מנעולים בכלל.
- הילד יכול לעבור לכל שיעור בכל רגע. הקורס רק *ממליץ* (השיעור הנוכחי בולט) ומעביר אוטומטית כשיש שליטה (ראו 5.5).
- **מובייל (<700px):** העמודה הופכת לפס אופקי נגלל בראש העמוד, השיעור הנוכחי במרכז.

### 4.3 אזור השיעור (מרכז)
- כותרת: "שיעור N · מפתח ה[שם]" + משפט אחד שמסביר את הרעיון.
- **סטפר 5 שלבים** (כמו מסילה עם תחנות): הושלם / נוכחי / עוד לא. כל תחנה לחיצה.
- אזור התוכן מתחלף לפי השלב.
- **כפתורי "קודם" ו"הבא" — תמיד פעילים**, גם אם השלב לא הושלם (דילוג חופשי קדימה ואחורה). משלב 5 "הבא" מוביל לשיעור הבא; משלב 1 "קודם" — לשיעור הקודם.
- מד דיוק קטן (דיוק במשחק התרגול / ציון המבחן האחרון) — מראה לילד כמה הוא קרוב למעבר.

## 5. חמשת השלבים

| # | שלב | מה זה | מתי מסומן ✓ | רכיב |
|---|---|---|---|---|
| 1 | סרטון הסבר | MP4 רגיל | צפייה ב-90% | `VideoStage` |
| 2 | התנסות אינטרקטיבית | סרטון אנימציה שעוצר בנקודות ושואל שאלה | ענה נכון על כל השאלות | `InteractiveVideoStage` |
| 3 | משחק תרגול | משחק קיים/חדש מ-MathPlatform | `GAME_OVER` עם כוכב אחד לפחות | `GameStage` |
| 4 | משחק העשרה | משחק נוסף, חופשי יותר | `GAME_OVER` (כל ציון) | `GameStage` |
| 5 | **מבחן מעבר** | סט שאלות קבוע על המפתח, בלי רמזים | ציון ≥ 90% | `TestStage` |

### 5.1 סרטון הסבר
- נגן HTML5, נטען רק בלחיצה (כמו בעמוד הנחיתה), עם poster.
- אפשר לצפות שוב תמיד, ואפשר לדלג (כפתור "הבא").

### 5.2 התנסות אינטרקטיבית — רכיב חדש אחד לכל השיעורים
- סרטון + רשימת **נקודות עצירה** בקובץ התוכן.
- בכל נקודה: הסרטון עוצר, מופיעה שכבה עם שאלה ו-2–4 תשובות (כפתורים גדולים, 44px+).
- נכון → אנימציית הצלחה קצרה, הסרטון ממשיך.
- לא נכון → רמז (טקסט מהקובץ), ניסיון נוסף. אחרי 2 טעויות — מראים את הפתרון וממשיכים.
- כל תשובה נשלחת כ-`ANSWER` דרך ה-SDK → נכנס לניתוח הטעויות הקיים.
- **אין צורך לבנות פעמיים:** אותו רכיב, רק קובץ תוכן שונה לכל שיעור.

### 5.3 + 5.4 משחקים
- נטענים דרך המנגנון הקיים (`/play/[gameId]` / `GameFrame`) בתוך אזור התוכן.
- צריך תוספת קטנה: פרמטר `returnTo=/course/lesson-03?stage=4` כדי שכפתור "המשך" במשחק יחזיר לקורס ולא לדשבורד.
- אפשר לשייך משחק קיים (למשל `math-addition-subtraction-001`) או ליצור חדש עם skill `new-game`.

### 5.4 מבחן מעבר — רכיב חדש אחד לכל השיעורים
- 10 שאלות (מספר בקובץ התוכן), אחת אחרי השנייה, בלי רמזים ובלי ניסיון שני.
- השאלות מוגדרות בקובץ התוכן של השיעור (אותו מבנה כמו שאלות ההתנסות), בסדר אקראי.
- בסוף: ציון באחוזים + הדמות מגיבה. ≥ 90% → חגיגה ומעבר לשיעור הבא. פחות → "כמעט! עוד תרגול ונסה שוב" + כפתורים: "חזרה למשחק התרגול" / "לנסות שוב".
- אפשר לגשת למבחן בכל רגע (גם בלי לעבור את השלבים הקודמים) — ילד שכבר יודע יכול להיבחן ולהתקדם.
- כל תשובה נשלחת כ-`ANSWER` (לניתוח טעויות), ונרשמת עם `stage = 5`.

### 5.5 מעבר בין שיעורים — לפי שליטה, לא לפי נעילה
- **שום דבר לא נעול.** שלבים ושיעורים פתוחים תמיד, עם דילוג חופשי.
- **מעבר אוטומטי — אחד משני תנאים, מה שקורה קודם:**
  1. **משחק התרגול (שלב 3):** דיוק ≥ **90%** על 30 התשובות האחרונות במשחק, עם לפחות 20 תשובות. (חלון אחרון — כדי שטעויות מההתחלה לא יתקעו ילד שכבר הבין.)
  2. **מבחן מעבר (שלב 5):** ציון ≥ **90%** בניסיון אחד.
  - כשאחד מהם מתקיים → מסך חגיגה קצר ("שלטת במפתח ה...!") ומעבר אוטומטי לשיעור הבא, שהופך ל"נוכחי".
  - ההתנסות (2) וההעשרה (4) לא נספרות לשליטה.
  - הספים בקובץ התוכן (`mastery`) — משנים בלי קוד.
- **מעבר ידני:** הילד יכול לעבור בעצמו בכל רגע. השיעור שעזב נשאר "בתהליך" (לא ✓) עד שיגיע בו לשליטה.
- **"השיעור הנוכחי"** = השיעור הראשון ברשימה שעוד אין בו שליטה. בכניסה לאתר נכנסים אליו.
- **שלב בתוך שיעור:** בסיום שלב (✓) עוברים אוטומטית לשלב הבא; הילד יכול לחזור אחורה או לדלג.

## 7. נתונים — Supabase (אותו פרויקט של mathplatform)

שתי טבלאות חדשות קטנות, כל השאר קיים:

**`course_enrollments`** — איזה ילד לומד בקורס
| עמודה | סוג |
|---|---|
| id | uuid PK |
| parent_id | uuid → auth.users |
| child_id | uuid → children |
| course_id | text (`'kidodo'`) |
| created_at | timestamptz |

ייחודי: `(child_id, course_id)`. הורה יכול להחזיק כמה שורות (כמה קורסים / ילדים).
`parent_access` = אילו קורסים נקנו; `course_enrollments` = לאיזה ילד שויך כל אחד.

**`course_progress`** — שלב אחד = שורה אחת
| עמודה | סוג | הערה |
|---|---|---|
| child_id | uuid → children | |
| course_id | text | |
| lesson_id | text | `lesson-03` |
| stage | int | 1–5 |
| completed_at | timestamptz | nullable |
| stars | int | nullable, למשחקים |
| score | int | nullable, ציון מבחן באחוזים |

PK: `(child_id, course_id, lesson_id, stage)`.

**`course_answers`** — כל תשובה בשיעור (לחישוב דיוק)
| עמודה | סוג |
|---|---|
| id | bigint PK |
| child_id | uuid → children |
| course_id | text |
| lesson_id | text |
| stage | int |
| correct | boolean |
| created_at | timestamptz |

**`course_mastery`** — שליטה בשיעור
| עמודה | סוג | |
|---|---|---|
| child_id, course_id, lesson_id | PK |
| mastered_at | timestamptz |
| via | text | `'practice'` / `'test'` |

RLS בכולן: הורה רואה רק ילדים שלו (כמו `child_lessons`).

- כל `ANSWER` שנשלח מתוך הקורס (יש `courseId` + `lessonId` בהקשר) נרשם גם ב-`course_answers`.
- **מבחן** נשמר כניסיון שלם: `course_progress.stage = 5` עם הציון האחרון (עמודה `score` int, nullable) — נוספת לטבלה.
- אחרי כל תשובה במשחק התרגול ובסיום כל מבחן השרת בודק את ספי ה-`mastery` → אם עבר, כותב ל-`course_mastery` ומחזיר `mastered: true` (הלקוח מציג חגיגה ומעביר).
- כוכבים ומטבעות ממשחקים ממשיכים לזרום ל-`progress` / `children.coins` כרגיל — הילד רואה אותם גם ב-MathPlatform.
