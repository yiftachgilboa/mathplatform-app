# חנות, מטבעות ודמות אישית

עודכן 2026-11-23 לפי ההחלטות של יפתח. בדיקת קונספט: `/course/shop-test` (בלי כניסה, בלי שמירה).

## הקונספט

- לומדים ← מרוויחים ← קונים קופסת הפתעה ← הדמות משתנה בכל המשחקים.
- בכניסה הראשונה הילד מגיע ישר לחנות, עם 100 מטבעות.
- אין שינוי בדמות בלי קופסה.
- קופסאות נגללות, כל אחת בצבע אחר, המחיר בגדול מתחת.
- קונים ← לוחצים ← נפתח ← יוצא פריט אקראי בצבע הקופסה.
- וי: הדמות לובשת (מחליף את הקודם). איקס: הפריט נעלם.
- אין חרטה ואין מלאי.
- פריט בחינם = קופסת מתנה. אפשר לתת על כל יעד.
- כוכבים = ציון בלבד. אין להם קשר למטבעות.

## המספרים — `content/shop/shop.json`

| שדה | מה זה | עכשיו |
|---|---|---|
| `testMode` | `true` = הכול עולה 0 | `true` |
| `startCoins` | מטבעות פתיחה | 100 |
| `boxPricePractices` | כמה תרגולים שווה קופסה | 10 |
| `rewards.*.first` | פעם ראשונה | סרטון 5, התנסות 5, משחק 10, העשרה 10, מבחן 20, שליטה 30 |
| `rewards.*.repeat` / `repeatPerDay` | חזרות | משחק: 10, עד 3 ביום |
| `giftBoxes.*` | קופסאות מתנה בפעם הראשונה | 0 |
| `boxes` / `items` | צבעים, גוונים, פריטים ומשקלים | 8 קופסאות, 6 סוגי פריטים |

- מחיר קופסה = `boxPricePractices` × מטבעות לתרגול. משנים תגמול ← המחיר משתנה לבד.
- גם המספר שהמשחק מציג מגיע מכאן (`KidodoPractice.reward()`).
- לסיום הבדיקה: `testMode: false`.
